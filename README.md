📊 Maven Fuzzy Factory Analysis
A complete e‑commerce analytics project analyzing website performance, customer behavior, and marketing KPIs using SQL and Excel Dashboards.

🔍 Project Overview
Maven Fuzzy Factory is a simulated e‑commerce company dataset designed to help analysts understand how users interact with the website, how marketing channels perform, and how business KPIs evolve over time.
This project focuses on extracting insights using SQL and presenting them through an interactive Excel dashboard.

🎯 Objectives
Analyze website traffic and user acquisition patterns

Evaluate conversion funnels and customer behavior

Measure marketing channel performance

Identify trends in orders, revenue, and repeat customers

Build an Excel dashboard to visualize key business metrics

🛠 Tools & Technologies

📈 Key Insights
